# Chat-O-Matic (聊聊机) 🚀

一个专为青少年设计的 AI 聊天伙伴，采用 Neo-Brutalism 风格设计，由 Next.js 16 和 Google Gemini 驱动。

![Chat-O-Matic Preview](public/window.svg)

## ✨ 功能特性

- **Neo-Brutalism UI**：大胆边框、鲜艳色彩和厚重阴影，打造独特视觉体验
- **实时流式响应**：打字机效果，实时观看 AI 思考和回复
- **聊聊机回复头像**：聊天窗口中的 AI 回答统一使用闪电机器人品牌形象
- **用户消息复制**：文字消息下方提供复制按钮，鼠标悬停或键盘聚焦时显示，手机和平板触控设备常驻显示，复制后显示勾选反馈。
- **友好错误反馈**：额度耗尽、访问受限或上游故障时，在对话区显示可关闭的中文提示，不再暴露原始 403/错误页
- **Markdown 渲染**：完整支持 Markdown 格式，包括表格、代码块和任务列表
- **句子拆解**：解释英文句子、询问“这句什么意思”、翻译并解释或分析长难句时，默认主动展示句子拆解卡，无需再次要求“拆解”。卡片包含原句、自然译文、句子主干、可点击的主语/谓语/从句等片段及必要词汇；点击片段查看其作用与说明，正文只补充必要信息，避免重复整份分析。明确要求只翻译、纯文字或不分析时遵守要求；已有卡片后的局部追问不重复生成整张卡。检查片段按原文顺序完整覆盖句子，异常或生成中的卡片显示独立提示。卡片随对话原文保存在历史中，沿用现有主题和手机排版。
- **针对段落追问**：有可追问段落的回复底部统一提供“追问某段”，iPad和手机平时不再逐段显示图标或预留右侧空白；点击入口进入选择模式，再轻点段落，只有选中的段落高亮并显示操作菜单，同一条回复一次只打开一个菜单。可点击“取消选择”、关闭菜单或按 Esc 退出，发送后自动退出；已有题目选择不会因切换模式丢失。桌面保留悬停或键盘聚焦显示的逐段快捷入口。普通回复、阅读材料、已提交题目解析和句子拆解说明使用同一套操作；可选择“没看懂”“举个例子”，英文段落可“拆解句子”，也可输入自己的问题。发送时自动带上对应原文，不引用整篇回答。长原文截取前1800字符，自定义问题最多600字符，控制在聊天输入上限内。生成期间入口暂时隐藏，追问不触发练习结束判断；涉及未提交题目时要求只给理解提示，不公布答案或补全空位。
- **互动答题卡与材料题组**：普通练习一次一道，支持单选、多选和判断；阅读理解与完形填空默认一篇文章配3道小题，文章只展示一次，每题独立选择并显示完成进度。全部小题选择后才能整组提交，提交前不展示任何答案或解析，提交后逐题判分并显示解析及本组答对数。“做3道阅读题”按一篇三题处理，“做3篇阅读”按三组逐篇进行；明确题量优先，每组支持1–6题，更多题量分组承接。完形使用连续编号空位，逐空对应单选题。新一组默认换材料，明确要求同一篇时保留文章并更换问题；组内问题围绕材料互补，不再按单题强制换文。卡片支持 Markdown 与数学公式，沿用三套主题和手机排版。提交仅更新卡片并保存选择状态，不新增用户气泡；单题与整组作答均可恢复历史，服务端按实际小题数统计和补充讲解上下文，未整组提交不计作答。保留旧版单题记录。生成中和无效格式有独立提示。判题依据模型提供的答案，用于日常练习，不代表独立核实；数据保存在浏览器中，答案并非考试级保密。
- **对话图表**：回答可直接展示柱状图、折线图和环形图，支持单组最多 24 项数据；柱状图与折线图在卡片右上角提供双向切换，默认采用生成时的图表类型，仅改变当前显示方式，不改动数据、顺序、来源或保存的原文，环形图保持原样。数据类型说明移至“查看数据”内；悬停、点击或键盘聚焦查看数值，展开数据表查看完整标签。沿用三套主题，宽图在手机端可横向滚动。区分用户数据、示例数据与参考数据，参考数据须附来源链接；来源标签不代表系统已核实。图表生成中显示占位提示，格式异常时提示重新生成，图表数据随文字保存在历史记录中。
- **清晰数学公式**：核心分数、求根公式和关键推导优先独立成行，居中适度放大并增加上下留白，手机端使用更紧凑的字号；较长推导优先分行对齐等号，超宽公式可从起始位置横向滚动查看。行内变量保持原有字号，含公式的文字行增加行距。新排版规则用于后续生成的回答；渲染端会兼容修复明确数学表达式中混用的单、双美元定界符，已有记录也可受益，不改写保存的原文或代码示例。
- **Google Gemini**：由 Gemini 3.5 Flash-Lite 模型驱动
- **AI 人设切换**：5 种个性鲜明的聊天角色（学习伙伴、科学怪博士、冒险故事家、哲学喵、吐槽达人），在统一设置面板中随时切换
- **人设专属开场卡片**：20 张快捷卡片按学习辅导、科学探究、互动叙事、哲思交流和轻松吐槽重新分工，并强化实验安全与连续互动。五个人设的卡片标题、点击发送的提示词、开场引导与输入框占位提示会随回复语言切换，支持简体中文、繁体中文、英、法、日、韩、西、德语；选择“自动”时开场卡片和提示保持中文。长标题可换行，适配手机窄屏；其他界面操作仍使用中文。
- **专注式侧边栏**：左侧提供新建对话、历史标题搜索框、收藏、历史记录和底部设置入口；搜索实时匹配收藏及普通历史标题，忽略英文大小写，支持一键清除。有收藏时自动置顶单列显示，取消收藏后回到历史记录
- **主窗口人设切换**：点击聊天窗口顶部的人设图标或名称打开切换面板，手机和平板使用相同入口；回答生成期间禁用切换；选择即生效，已有对话会先自动保存，再为新人设开启对话，无需二次确认。设置页切换后保持在设置页。
- **主区域设置页**：设置直接替换主聊天区域，保留左侧导航，点击“返回聊天”或按 Esc 回到当前对话；选择新建对话或历史记录也会返回聊天。采用紧凑间距和选项卡，宽屏下字体与字号并排，尽量在一屏展示，小屏保留滚动。用户资料、人设、联网模式和主题配色集中管理并立即保存；切换人设时会自动保存当前对话。
- **阅读偏好**：默认字体、系统字体和宋体风格三种字体，14 / 16 / 18 / 20 四档字号，提供即时预览并保存到本地。作用于聊天正文与输入框，代码和数学公式保留专用字体；输入框最小 16px，避免手机聚焦时自动放大。字体风格的具体字形取决于设备已安装字体。
- **回复语言**：设置页可选择自动跟随提问语言、简体中文、繁体中文、英语、法语、日语、韩语、西班牙语或德语。自动保存到当前浏览器，从下一次回复生效，覆盖普通提问、快捷操作、重新生成及练习总结；切换人设、新建对话或恢复历史仍沿用当前语言偏好。翻译、双语输出或语言练习中的明确任务要求优先，引用原文、代码及卡片数据结构保持所需格式。界面按钮与历史原文不随设置翻译；自动模式下练习总结的固定统计文字默认使用简体中文。
- **本地头像裁剪**：可从设备选择 JPG、PNG 或 WebP 图片，拖动缩放完成圆形头像裁剪；结果仅保存在当前浏览器
- **历史记录管理**：最多保留 100 条对话，支持逐条删除
- **智能对话标题**：首轮回答完成后，根据用户问题和助手回答在后台生成简短主题标题，后续聊天保留该标题；生成失败时保留临时标题，不影响聊天。历史列表移除左侧气泡，收藏记录保留星标。
- **对话收藏夹**：最多收藏 10 条历史对话；记录超出上限时优先清理最旧的未收藏对话
- **联网控制**：在设置中选择自动联网、强制联网或关闭联网；请求期间以动态图标实时区分“思考中”和“联网搜索中”。回答下方仅显示“已联网 · 参考 X 个来源”，按不同来源链接计数并去重（忽略页面锚点），避免同域名页面或搜索跳转链接被合并成一个，不再逐条展示来源卡片；没有来源明细时只显示“已联网”，正文引用链接继续保留。
- **按场景显示回复操作**：普通回答显示“讲简单些 / 举个例子 / 出道题 / 检查事实”；普通单题沿用换题、续题、讲解与难度调整；材料题组未提交时提供换组和下一组难度调整，提交后显示“再练一组 / 讲解错题 / 简单一点的一组 / 难一点的一组 / 练习总结”。难度调整出一组新材料练习，不改变正在作答的小题；“再练一组”明确追加一组，达到原定题量后仍可继续；“讲解错题”优先分析本组错题，全对时归纳思路。讲解后可简化解析，自动总结和历史恢复后保留题组续练操作。服务端按当前对话保留的已提交小题精确统计题数、对错和正确率，展示环形图，再由 AI 提供待加强知识点与建议；未提交不计为答错，题量有限或全对时不编造弱项。做题操作统一放在回复下方；生成期间操作禁用，旧回复保留复制与“追问某段”入口。
- **完整 PWA 品牌图标**：统一使用闪电机器人 Logo，并提供 favicon、Apple Touch Icon 与 maskable 安装图标
- **人设历史记录**：每段历史对话会保存并显示当时使用的人设，恢复对话时自动切回对应角色
- **可靠重新生成**：重新生成图片对话时会保留原始图片和对应人设
- **按需代码高亮**：仅在回复出现代码块时加载 Prism，减少普通聊天的初始脚本
- **质量保障**：API 请求校验与历史人设迁移均有自动化测试覆盖
- **多主题配色**：Sunflower / Ocean / Peach 三套 Neo-Brutalism 主题自由切换；Ocean 采用午夜海沟与生物荧光配色，并优化深色界面对比度
- **接口防护**：严格校验消息、图片和请求体，并通过 Vercel WAF 执行跨实例限流
- **响应式聊天布局**：桌面应用最大宽度为1440px，普通 AI 文字回复内容宽度约780px，图表、题组和句子拆解卡内容可扩展至1120px，不再统一限制为聊天区域的80%。混合回复中的说明文字及卡片内长文仍限制阅读行宽；仅包含有效卡片的回复直接以卡片作为容器，保留头像和操作栏，减少双层边框、阴影和内边距。输入区域与聊天内容对齐。1280px以下（包括多数 iPad 横竖屏）导航默认收起为抽屉，支持关闭按钮、遮罩及 Esc 关闭；宽桌面默认显示固定导航，可随时展开或收起。手机继续使用原有全屏布局，宽图表仅在卡片内部滚动。
- **移动端沉浸式聊天**：全屏动态视口适配 iPhone 键盘与安全区，宽版 AI 消息和一体式输入栏减少遮挡并提升正文可读性
- **青少年友好**：专为 10-16 岁好奇青少年优化的对话体验
- **统一对话原则**：五个角色优先完成当前请求，减少固定套话和强行追问；练习、谜题与冒险逐轮推进，明确区分事实、类比与虚构。情绪支持时收敛角色表演，所有角色共享实验安全与隐私边界。
- **来源与审核**：联网回答要求关键事实对应真实来源，搜索失败时说明不确定性；昵称以数据形式传入，审核仅接受严格的有效结果，异常输出提示重试。

完成约定题数后，用户再次发送“继续”等消息、系统判断本组练习应结束时，会直接展示可视化练习总结：服务端统计已提交题目的对错、正确率及环形图，再生成知识点分析和建议，不只提示已到题数上限，也不额外询问是否需要总结。已作答且没有待提交题目时，普通文字请求会先经过一次简短的结构化结束判断；普通追问继续走原有聊天和联网流程。“再来一题”和难度调整等卡片操作直接沿用原有行为，不触发结束判断；明确追加题目时仍可继续练习。自动总结在历史恢复后保留续题操作，统计范围仍为当前对话保留的已提交作答记录。

## 🛠️ 技术栈

- **框架**: [Next.js 16](https://nextjs.org/) + TypeScript
- **样式**: [Tailwind CSS 4](https://tailwindcss.com/)

- **UI 组件**: [Radix UI](https://www.radix-ui.com/) & [Lucide React](https://lucide.dev/)

- **Markdown**: [react-markdown](https://github.com/remarkjs/react-markdown) & [remark-gfm](https://github.com/remarkjs/remark-gfm)

## 🚀 快速开始

### 前置要求

- Node.js 20.9+
- pnpm（推荐）
- Google AI Studio API Key（[获取地址](https://aistudio.google.com/apikey)）

### 安装步骤

1. 克隆仓库：

   ```bash
   git clone https://github.com/phoenixlwpapix/chat-o-matic.git
   cd chat-o-matic
   ```

2. 安装依赖：

   ```bash
   pnpm install
   ```

3. 配置环境变量：
   在项目根目录创建 `.env.local` 文件，添加你的 Gemini API Key：

   ```env
   GOOGLE_GENERATIVE_AI_API_KEY=your_api_key_here
   ```

4. 启动开发服务器：

   ```bash
   pnpm dev
   ```

5. 在浏览器中打开 [http://localhost:3000](http://localhost:3000)

## 🔧 配置选项

### 更换模型

在 `app/api/chat/route.ts` 中修改模型：

```typescript
model: google("gemini-3.5-flash-lite"), // 或其他可用模型
```

可用模型包括：

- `gemini-3.5-flash-lite` - 低延迟、低成本的稳定模型（当前使用）

### 生产限流

Vercel 项目已配置 `Chat API rate limit` WAF 规则：

- 路径：`/api/chat`
- 维度：客户端 IP
- 限额：每小时 30 次
- 超限动作：Rate Limit，持续 1 小时

应用内限流只是二次防护；新建 Vercel 项目时必须同步配置上述 WAF 规则。

### 请求限制

- 请求体最大 4 MiB
- 最多 40 条历史消息
- 单条用户消息最多 3000 字符
- 每条消息最多 4 张图片
- 单张图片最大 1 MiB，仅允许 JPEG、PNG、WebP 和 GIF

历史记录使用 schema v4，并为旧数据自动补充默认人设、联网模式和收藏状态，同时忽略旧版本遗留的学习模式字段。历史记录最多保留 100 条，收藏夹最多保留 10 条；达到历史上限后新增对话时，会优先清理最旧的未收藏记录。最近选择的人设、联网模式、回复语言及阅读偏好另存于 schema v5 的 `chat-o-matic-preferences`，刷新页面和新建对话时继续沿用；旧设置自动补充“自动”回复语言；主题偏好继续独立保存。

标题通过 `/api/chat/title` 额外调用一次 Gemini（不联网），最多传入首问 3000 字符和首答前 6000 字符。生成结果与 `titleGenerated` 状态保存在本地历史记录中；旧记录在重新打开后可补全标题。后台标题更新不会改变历史排序，也不会恢复已删除的记录。该接口沿用应用内限流；生产环境应将其纳入 Vercel WAF 的路径防护。

每条助手消息同时保存精简的联网摘要（是否联网及去重后的来源数量），刷新后重新打开历史记录仍能显示联网标识，无需保存完整搜索工具结果。修复前已丢失来源信息的旧记录无法自动补回。

### 人格回复工具与冒险行动卡

- 学习伙伴默认显示“讲简单些、举个例子”，“出道题”收进更多操作；科学怪博士显示“讲讲原理、举个实例”。哲学喵仅在较充分的讨论后提供“换个角度”，开场倾听不显示固定学习按钮。冒险故事家、吐槽达人不显示固定学习按钮。
- “检查事实”收进更多操作；复制、重新生成继续保留。各人格实际进入答题时，仍使用原有的练习控制按钮。短回复隐藏“追问某段”入口，较长回复或可追问的卡片保留入口。
- 冒险故事家在互动场景中输出 `choice` 代码块：`{"prompt":"接下来怎么做？","options":["沿河前行","走进森林"]}`。每回合一张卡，2～3个行动；点击立即发送所选行动，旧卡不可再次提交，历史记录保留选择。自由输入自己的行动同样有效。
- 行动卡与故事正文同宽，最大约 780px，窄屏自适应铺满；选项整行可点。行动卡没有标准答案，不参与答题统计；完整故事和结局不强加选项。卡片流式生成完成后才开放点击，格式异常时提示用户自由输入。
